# CRUD-MySQL-Python
CRUD de gerenciamento de produtos desenvolvido em Python e MySQL.

Projeto realizado em Python com integração ao banco de dados MySQL com o objetivo de praticar Python + MySQL.

O código permite gerenciar produtos através de cadastro, listagem, atualização e exclusão(CRUD)

## Objetivos do projeto

- Praticar conexão entre Python e MySQL
- Aprender manipulação de dados em banco relacional
- Aplicar conceitos de organização de código
- Trabalhar e praticar operações CRUD

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Atualização de dados
- Exclusão de produtos

## Tecnologias
- Python
- MySQL
- GitHub

## Aprendizado

Foram fixados conceitos de Python e MySQL, juntamente com cursos gratuitos das tecnologias aplicadas, documentação e ferramentas de apoio como IA para compreender o funcionamento e o motivo das implementações realizadas.
