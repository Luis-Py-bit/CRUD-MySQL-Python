# CRUD-MySQL-Python
CRUD de gerenciamento de produtos desenvolvido em Python e MySQL.

Projeto realizado em Python com integração ao banco de dados MySQL com o objetivo de praticar Python + MySQL.

O código permite gerenciar produtos através de cadastro, listagem, atualização e exclusão(CRUD)

## Objetivos do projeto

- Praticar conexão entre Python e MySQL
- Aprender manipulação de dados em banco relacional
- Aplicar conceitos de organização de código
- Trabalhar e praticar operações CRUD

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Atualização de dados
- Exclusão de produtos

## Tecnologias
- Python
- MySQL
- GitHub

## Como executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd CRUD-MySQL-Python
```

3. Instale a dependência necessária:

```bash
pip install mysql-connector-python
```

4. Configure a conexão com o banco de dados no arquivo `conexao.py`:

```python
host="localhost"
user="root"
password="SUA_SENHA"
database="sistema_produtos"
```

5. Certifique-se de que o banco de dados MySQL e a tabela de produtos estejam criados.

6. Execute o projeto:

```bash
python main.py
```

Pronto! O sistema estará funcionando.
